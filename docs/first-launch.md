# 桌面版首次打开

从[项目 Releases](https://github.com/LiuKay/musicdl-soundtrack/releases) 下载，完整解压到可写目录后打开应用。Windows 请保留 `Soundtrack.exe` 旁边的支持文件。

macOS 如果提示「无法验证开发者」或「Apple 无法检查是否包含恶意软件」，先核对下载来源。如果确认是可信的原始发布包，尝试打开一次后，在「系统设置 → 隐私与安全性」找到「仍要打开」，再确认打开。该操作只为这个应用建立例外。

如果提示文件损坏、应用将损坏电脑或被检测为恶意软件，请停止打开并重新核对发布文件，不要关闭系统安全保护。

这些步骤依据 [Apple 关于安全打开应用的说明](https://support.apple.com/en-us/102445)。当前项目发布流程没有配置 Developer ID 公证；应用内版本检查不会自动安装，也不会替你改变系统安全设置。

## English

Download from the [project Releases](https://github.com/LiuKay/musicdl-soundtrack/releases) and extract the complete package. Keep the Windows executable's supporting files together.

If macOS cannot verify the developer, first confirm that you downloaded an original package from a trusted source. After trying to open it, use System Settings → Privacy & Security → Open Anyway, then confirm. This creates an exception for that app only.

For damaged-app or malware warnings, stop and verify the release files rather than disabling system protection. The project does not currently configure Developer ID notarization. Updates are checked read-only and installed manually. See [Apple's instructions](https://support.apple.com/en-us/102445).
